# Examples

This folder contains example files for RetroWowUpdateResp.

## sample-update.txt

A sample update response with inline comments showing the recommended file
format. Copy this file when creating a new update response and replace the
title, date, status, and body with your own values.

## Rules

- Do not commit real credentials or secrets here.
- Keep inline comments accurate; update them when the file changes.
- No emojis in file content or commit messages.
